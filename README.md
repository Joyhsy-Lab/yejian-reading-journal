# 页间 · 读书笔记

用来整理书架、记录读书笔记、计时和回顾每月阅读统计的静态网站。

## 打开网站

在线版见 [页间](https://yejian-reading-journal.smilehuan8.chatgpt.site/)。

本地运行时，在仓库根目录执行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000`。项目不需要安装前端依赖，也没有构建步骤。

书架、笔记和阅读记录存放在当前浏览器的网站存储中。跨浏览器、设备或网址迁移时，请在原网站使用「数据备份 → 导出备份」，再到目标网站恢复。恢复会替换目标网站当前保存的数据。
